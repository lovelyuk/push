# 바둑 한판 (웹 바둑 게임)

브라우저에서 바로 즐길 수 있는 2인용 바둑 게임입니다. 9/13/19 크기의 바둑판을 선택할 수 있고,
기본적인 규칙(자살수 금지, 코 규칙, 패스/기권 등)을 지원합니다.

## 실행 방법

1. 저장소를 클론하거나 다운로드합니다.
2. `index.html` 파일을 브라우저에서 직접 열면 게임을 바로 시작할 수 있습니다.
   - 별도의 빌드나 서버가 필요하지 않습니다.

## 주요 기능

- 9, 13, 19 줄 바둑판 지원 (상단 드롭다운에서 선택)
- 흑/백 차례 표시, 포획 수 집계, 최근 수 정보 표시
- 자살수 방지 및 기본 코(ko) 규칙 적용
- 패스, 기권, 한 수 무르기, 새 게임 시작 기능 제공
- 모바일 환경에서도 사용하기 편하도록 반응형 UI 적용

## 게임 방법

1. 빈 교차점을 클릭하면 돌이 놓입니다.
2. 상대 돌의 마지막 자유도를 막으면 자동으로 포획됩니다.
3. 양측이 연속으로 패스하면 게임이 종료됩니다.
4. `한 수 무르기` 버튼을 눌러 이전 상황으로 되돌릴 수 있습니다.
