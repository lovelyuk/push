# Baccarat CLI Game

간단한 커맨드라인 기반의 바카라 게임입니다. 게임을 시작하면 100개의 코인이 제공되며,
코인이 0이 되면 자동으로 종료됩니다. 각 라운드마다 플레이어, 뱅커, 타이 중 하나에
코인을 베팅할 수 있습니다.

## 실행 방법

```bash
python baccarat.py
```

## 게임 규칙

- 플레이어는 매 라운드 베팅 금액과 대상을 선택합니다.
- 베팅 대상: 플레이어(P), 뱅커(B), 타이(T).
- 플레이어와 뱅커는 표준 바카라 규칙에 따라 2~3장의 카드를 받습니다.
- 승자 판정은 각 손의 점수(0~9, 10은 0으로 계산)를 비교하여 결정합니다.
- 배당:
  - 플레이어 / 뱅커 승: 1배 (베팅 금액과 동일한 수익)
  - 타이: 8배 (베팅 금액의 8배 수익 + 원금 반환)
  - 타이 발생 시 플레이어 또는 뱅커에 베팅했다면 베팅 금액이 반환됩니다.
