# 웹 텍사스 홀덤 포커 데모

단순한 데모용 텍사스 홀덤 포커 게임입니다. 플레이어와 딜러에게 카드를 나눠주고, 플롭-턴-리버-쇼다운 단계를 진행하면서 승부를 확인할 수 있습니다. 베팅 기능은 포함되어 있지 않으며, 패 분석과 승패 판정에 초점을 맞춘 학습용 프로젝트입니다.

## 실행 방법

별도의 빌드 과정 없이 정적 파일만으로 동작합니다. 다음 방법 중 하나를 사용해 `index.html`을 브라우저에서 열면 됩니다.

1. 파일을 직접 더블 클릭하거나 브라우저에서 `index.html`을 열기
2. 간단한 웹 서버 실행 후 접속
   ```bash
   # 예시: Python 3 내장 서버 사용
   python -m http.server 8000
   # 브라우저에서 http://localhost:8000/index.html 접속
   ```

## 플레이 방법

1. **게임 시작** 버튼을 눌러 카드를 배분합니다.
2. 각 단계별 버튼으로 플롭, 턴, 리버를 순서대로 공개합니다.
3. 마지막으로 **승부 보기** 버튼을 누르면 쇼다운이 진행되며 승패가 결정됩니다.
4. 쇼다운 결과는 화면 상단 메시지와 카드 하이라이트를 통해 확인할 수 있습니다.
5. 다시 플레이하려면 **새 게임** 또는 **초기화** 버튼을 눌러 새 덱으로 시작합니다.

## 주요 기능

- 52장의 표준 덱 생성 및 셔플
- 텍사스 홀덤 규칙에 따른 단계 진행
- 7장 중 최적의 5장 조합을 탐색하여 패 랭킹 계산
- 플레이어와 딜러의 패 비교 및 결과 메시지 출력
- 사용된 카드 하이라이트, 단계별 안내 메시지 제공
