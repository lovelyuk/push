# 웹 테트리스

간단하고 반응형인 웹 테트리스 게임입니다. 순수 HTML, CSS, JavaScript만으로 구현되어 있어 별도의 빌드 과정 없이 실행할 수 있습니다.

## 실행 방법

1. 저장소를 클론하거나 다운로드합니다.
2. `index.html` 파일을 브라우저로 열면 바로 게임을 즐길 수 있습니다.

## 조작법

- <kbd>←</kbd> / <kbd>→</kbd>: 블록 좌우 이동
- <kbd>↓</kbd>: 소프트 드롭(빠르게 내리기)
- <kbd>Space</kbd>: 하드 드롭(바닥까지 즉시 내리기)
- <kbd>Q</kbd> / <kbd>E</kbd> 또는 <kbd>↑</kbd>: 블록 회전
- <kbd>Enter</kbd>: 게임 오버 이후 재시작

## 특징

- 7개 테트로미노가 균등하게 등장하도록 가방 랜덤 방식을 사용합니다.
- 레벨이 올라갈수록 자동 낙하 속도가 빨라집니다.
- 다음에 등장할 블록 목록과 현재 점수, 레벨, 지운 줄 수가 실시간으로 표시됩니다.
- 게임 오버 시 최종 점수를 안내하며 버튼이나 Enter 키로 즉시 재시작할 수 있습니다.
